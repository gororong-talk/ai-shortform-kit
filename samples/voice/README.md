# 목소리 비교 샘플 (전자책 3장 사례 7)

같은 대본 4줄을 두 가지로 읽었습니다. 2026-11-18 생성, 가공 없음.

| 파일 | 도구 | 비용 |
|---|---|---|
| `02_fish_plain.mp3` | Fish Audio S2-Pro, 감정 태그 없음 (보이스 f_soft_shorts) | 1분에 약 $0.02 |
| `03_fish_emotion.mp3` | 같은 Fish 보이스 + 줄마다 감정 태그 | 같음 |

무료 TTS 비교는 `scripts/generate_narration_edge.py`로 직접 생성하세요.

대본:

```
예비 시아버지가 저희 부모님을, "금수 같은 것들"이라 불렀습니다.
결혼을 전제로, 십 개월을 만난 사람이 있었어요.
양가 인사만 남은, 그런 사이였죠.
그이는 자기 집안을, 끔찍이도 싫어했습니다.
```

감정 태그 버전 입력:

```
[angry] 예비 시아버지가 … [break] [slightly sad] 결혼을 전제로, … [calm] 양가 인사만 … [slightly sad] 그이는 …
```

태그는 소리 내 읽히지 않고 말투에만 반영됩니다. 다시 만들려면 `scripts/generate_narration_fish.py`(감정 태그는 각 줄 머리에 `[태그]`).
