## 1. 원무과장의 실제 업무 (만수의 하루)

원무과(原務課)= 병원의 '돈과 절차'를 총괄하는 행정 부서. 진료부(의사)·간호부와 별개 라인으로 **재단 사무국 직속**인 경우가 많다(그래서 만수는 재단의 사람).

**핵심 관장 업무:**
1. **수납(收納)**: 외래·입원·퇴원 수납창구 관리. 진료비 계산서·영수증 발행, 현금·수표·지로 수납, 일계표(日計表) 마감. 하루 매출을 재단에 보고.
2. **미수금(未收金) 관리** ← 극의 심장: 미수금대장 관리, 독촉, 보증인 확보, 퇴원 저지, 상각(償却) 판단. IMF기엔 이게 업무의 절반.
3. **입·퇴원 수속**: 입원약정서·보증금 예치·퇴원 정산. **입원보증금(예치금)** 을 미리 받아 미수를 방지 → 돈 없는 환자는 입원 자체가 막힘.
4. **보험청구**: 환자별 조합 확인 → 진료비 중 보험자부담분을 각 조합/공교에 청구(요양급여비용 청구). **삭감(사정)** 대응·이의신청.
5. **진단서·제증명 발급 수수료**, 영안실·장례식장 사용료 정산(→ 지하 순덕의 세계와 접점).
6. **재단 보고**: 병상가동률·수납률·미수금 잔액을 5층에 올린다. **수납률이 만수의 성적표.**

**의사·간호부와의 마찰(극적 연료):**
- 의사(도현)는 "일단 살리고 본다" → 만수는 "보증금·수납부터". **응급실 1층에서 돈과 생사가 정면충돌**(카논 무대).
- 간호부(정혜)는 미수 환자를 몰래 봐주거나 퇴원을 늦춘다 → 만수의 수납률을 갉는다. 만수가 "규정"으로 병동을 압박 → 병동은 그를 '저승사자'로 부른다.
- 의국은 원무과를 '장사꾼', 원무과는 의국을 '돈 모르는 이상주의자'로 본다.

## 2. IMF기 미수금 회수의 실제 (★ 개연적 재구성 + 시대 사실)

IMF 직후 병원 미수금은 폭증했다. 실직·부도로 입원비를 못 내는 환자, 퇴원 후 잠적, 야반도주가 속출. 원무과의 회수 실무:

- **입원보증금 선납**: 입원 시 며칠치 예치금을 걸게 함. 이걸 못 내면 입원 거절/지연 → **오만복 같은 환자가 문턱에서 막히는 지점.**
- **신원보증인·연대보증**: 입원약정서에 **연대보증인(가족·직장)** 도장·인감을 받음. 보증인이 실직 가장이면 회수가 다시 막힌다. 만수가 "도장 하나만"을 반복하는 이유.
- **퇴원 저지(사실상 인질)**: 미납 시 **퇴원 정산 전 퇴원 불가** 관행. 짐 싸서 나가려는 환자를 원무과 직원이 막아섬. 법적으론 회색지대지만 당시 광범위했다. → 만수의 "밤에 짐 싸시면 내가 다 뭅니다".
- **야반도주 추적**: 주소지·직장으로 독촉장 발송, 방문 독촉. IMF기엔 주소가 다 흩어져 회수 불능이 태반.
- **상각·손실 처리**: 회수 불능 미수는 대손 처리 → 재단은 이 손실을 **다른 장부 조작으로 메우려는 유인**(→ §4 이중장부 연결).
- **감정 마찰**: 죽어가는 환자 보호자에게 돈을 말해야 하는 직업 → 원무과 직원의 자기혐오·냉소가 직업병. 만수의 이중성이 여기서 자란다.

> ★검증 필요: '퇴원 저지'의 당대 합법성 경계, 입원보증금 액수 관행은 개연적 재구성. 미수금 폭증·야반도주·소멸시효 3년은 확인된 방향.

## 3. 의보통합 전 — 진료비 청구·삭감의 실무 (조합별 세계)

- 환자 접수 시 **의료보험증(조합 발행)** 을 받아 소속 조합/공교/지역을 확인. 자격 확인이 안 되면 **일단 자비(전액) 처리 후 나중 환급** — 자격 시비가 흔했다.
- 진료비 = **본인부담금(환자)** + **보험자부담금(조합 청구)**. 원무과는 조합별로 요양급여비용 명세서를 작성·청구.
- **삭감(査定)**: 심사에서 "과잉진료·기준초과"로 깎임 → 병원 손실. 원무과·의국이 삭감 사유를 놓고 다툰다. 삭감을 줄이려 진료기록을 '맞추는' 유혹.
- **조합 재정 편차** ✔: 작은 조합은 조합비가 바닥나면 **진료비를 늑장 지급/체불** → 병원 자금난 가중. 의사회와 지역조합이 실력대결을 벌인 기록도 있다.
- **극작 함의**: 만수는 "이 환자는 어느 조합, 저 환자는 자비"를 순간 판별하는 능력자. 삭감을 피하려 서류를 손보는 습관이 **이중장부로 가는 경사면**이다.

## 4. 지방 사학재단 병원의 회계 비리 구조 (★ 개연적 재구성)

카논: "이사장 일가의 사금고화, 리베이트, 특혜진료가 관행처럼 굳어 있음." 이게 실제로 어떻게 굴러가는가 — 개연적 메커니즘:

**(a) 진료비 부풀리기·허위청구**
- 실제보다 검사·처치를 늘려 잡거나(과잉·허위), 오지 않은 진료를 청구. 삭감을 감안해 애초 부풀려 청구하는 관성. → 초과분이 재단 여유자금으로 흘러든다.

**(b) 약가·재료 리베이트**
- 의약분업 전이라 병원이 약을 직접 구매·조제. 제약사·의료기 납품가에 **리베이트(뒷돈)**. 장부엔 정상가, 실구매가와의 차액이 비자금. 만수 같은 원무·구매 라인이 숫자를 맞춘다.

**(c) 이중장부(카논 핵심)**
- **감사용(가짜) 장부**: 세무·교육청 감사에 내놓는 깨끗한 버전. 원무과 캐비닛.
- **실제(진짜) 장부**: 리베이트·부풀린 수입·특혜 무마비·인건비 부풀리기(유령직원)까지 담은 버전. 이사장실 금고.
- **다리 놓는 사람 = 원무과장 만수.** 수납 실적을 재구성해 두 장부의 앞뒤를 맞추는 게 그의 '진짜' 업무. 그래서 재단은 학벌 없고 나갈 데 없는 그를 앉혔다.

**(d) 재단 사금고화**
- 학교법인 전입금·병원 수익을 이사장 일가의 사적 용도(부동산·자녀 유학·용돈)로 전용. 유령 용역·과다 자문료로 빼돌림. 병원은 만성 '적자'로 보이게 하고 실제 이익은 위로.

**(e) 특혜진료(재호와 연결)**
- 이사장 아들 **윤재호의 무면허 준의료행위**·VIP 특혜진료를 정상 진료로 서류화. 사고가 나면 미수금 상각·기타비용으로 분식(粉飾)해 덮음. → **18년 전 만수 아내 은폐의 회계 처리 방식과 같은 수법**(인물 §6-B). 만수가 이중장부를 아는 뿌리.

> ★검증 필요: 구체 수법은 당대 사학·병원 비리 유형의 개연적 종합. 리베이트·이중장부·사금고화 자체는 시대적으로 충분히 개연적.

## 5. 실제 용어 · 서류 · 소품 (콘티·미술 레퍼런스)

**서류·장부(대부분 수기):**
- **원장(元帳)·수납대장·미수금대장**: 만년필로 적는 큰 장부철. "침 발라 넘기는" 소리.
- **일계표(日計表)**: 하루 수납 마감표.
- **입원약정서 / 연대보증서**: 보증인 도장·인감증명 첨부.
- **진료비계산서·영수증**: 외래/입원, 본인부담·보험부담 구분란.
- **요양급여비용 명세서(보험청구서)**: 조합별.
- **독촉장 / 최고장(催告狀)**: 미수 회수용 발송 문서.
- **의료보험증**: 조합 발행, 접수창구 확인용.
- **상각(대손) 결의서**: 회수불능 미수 손실 처리.

**도구·소품:**
- **주판**(과도기 병존) + **전자계산기**, 만년필·볼펜·**인주·직인·개인도장**, 스탬프(수납/미납 도장), 장부철·바인더, 금전출납 현금함, **자기앞수표·현금다발**, **국민은행 지로용지·무통장입금증**, 사무실 회전식 명함첩, 재떨이(실내 흡연), 형광등·미색 파티션.

**말·표현(대사에 뿌리기):**
- "보증금", "선납", "일계 마감", "삭감 먹었다", "상각 쳐라", "미수 잔액", "조합에 물어봐(자격 확인)", "장부 맞춰라", "위(재단)에 올린다", "수납률", "예치금", "퇴원 정산", "최고장 나갔나".

## 6. 극적 활용 노트 (직업 → 비트)

- **1층 원무과 창구** = 돈(수납)과 생사(응급실)가 붙어 있는 구조 → 만수의 규정과 도현의 응급처치가 물리적으로 충돌하는 무대. 오만복이 막히는 곳.
- **미수금대장** = 만수의 무기이자 양심의 장부. 그가 몰래 유예 처리한 몇 줄이 이중성의 증거.
- **이중장부** = 재단 비리 전모(연재 훅 ①)의 물증. 원무과 캐비닛(가짜) ↔ 이사장실 금고(진짜)의 지리적 대비.
- **보증인 도장 하나** = IMF 실직 가장(정혜 남편 한동철류)의 무력함을 압축하는 소품.
- **조합 자격 확인** = 환자의 계급·처지를 순식간에 분류하는 장치(직장조합=든든, 지역조합=불안정, 자비=벼랑).
