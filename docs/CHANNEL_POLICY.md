# 📣 CHANNEL_POLICY.md — 플랫폼 업로드 정책

> TikTok / YouTube Shorts / Instagram Reels 업로드 시 준수할 공식 정책 + 자체 운영 기준.
> 사연 기반 숏폼은 **AI 생성 라벨 + 명예훼손 방지** 두 축이 핵심.
>
> 최종 수정: 2026-04-23 (BGM: Lyria → ACE Step v1.5 전환 반영)

---

## 1. AI 생성 콘텐츠 라벨 (필수)

세 플랫폼 모두 **AI 생성/수정된 현실적 콘텐츠**에 라벨 부착을 요구한다. 우리 파이프라인은 Imagen4(이미지) + ElevenLabs(음성) + Kling(영상) + ACE Step(음악) 이 섞여 있으므로 **항상 AI 라벨을 켠다**.
> 참고: 2026-04-22 이전에 제작된 청춘의 청구서 계열 영상은 BGM 이 **Lyria** 기반 (기록물 유지).

### YouTube Shorts

- 업로드 시 **"변경되거나 합성된 콘텐츠 포함"** (Altered or synthetic content) 체크박스 ON
- 상세 설명:
  - 실제 인물처럼 보이는 합성 → 반드시 체크 (주인공이 Imagen4 생성이므로 해당)
  - AI 음성/음악 → 체크
- 결과 표시: 영상 설명란에 "변경된 콘텐츠: 소리 또는 시각 요소가 크게 편집되거나 디지털로 생성됨" 라벨 자동 노출

### TikTok

- 게시 화면 → **"더 보기"** → **"AI 생성 콘텐츠" 토글** ON
- 완전 AI 생성 영상의 경우 TikTok 이 자동 감지할 수도 있으나, **수동으로 먼저 켜는 것이 안전**
- 체크 조건: 현실적 장면/인물/음성이 AI 로 생성되거나 크게 수정된 경우 (= 우리 콘텐츠 해당)

### Instagram / Meta

- 릴스 업로드 시 **"AI 정보 라벨 추가"** (Add AI info label) ON
- Meta 의 자동 감지(IPTC 메타데이터)도 있지만 **수동 선언 권장**

### 자체 기준

- **설명란 문구 (세 플랫폼 공통)**:
  - 한국어: "🤖 이 영상은 AI(Imagen4·ElevenLabs·Kling·ACE Step)로 생성·편집되었습니다."
    - (2026-04-22 이전 업로드분은 "Lyria" 표기 유지)
  - 영어: "🤖 This video was generated and edited with AI tools."
- 해시태그: `#AI영상 #AI콘텐츠 #AIcontent`

## 2. 명예훼손 / 사생활 침해 방지

사연 기반 콘텐츠는 원본이 **커뮤니티 등 커뮤니티 글**이므로, 실제 인물로 특정될 위험을 완전히 제거한다.

### 절대 금지

- ❌ **실제 방송명** (예: "라디오스타", "썰전") → "어떤 TV 프로그램" 등으로 치환
- ❌ **연예인·공인 실명** (예: "김연예인") → 일반명사 ("유명인", "배우") 로 치환
- ❌ **브랜드명** (예: "삼성전자", "구찌") → 업종명 ("대기업", "명품브랜드") 로 치환
- ❌ **실명 + 식별 가능 정보** 조합 (직장명 + 학교명 + 지역 등)

### 각색 원칙

- **지역 일반화**: "서울 강남구 역삼동" → "수도권 한 도시"
- **직업 일반화**: "ㅇㅇ병원 정형외과 의사" → "의료계 종사자"
- **나이 10년 단위 반올림**: "32세" → "30대"
- **시간 흐리기**: "작년 12월 24일" → "지난 겨울"
- **영상 말미 고지**: 설명란에 "본 영상은 각색된 사연이며, 실제 인물/단체와 무관합니다." 명시

### 게시 전 셀프 체크리스트

- [ ] 실제 방송/프로그램명이 일반명사로 치환됐는가?
- [ ] 등장인물의 실명/직장명/학교명이 제거됐는가?
- [ ] 지역이 "광역권 수준"으로 흐려졌는가?
- [ ] 브랜드명이 업종명으로 치환됐는가?
- [ ] 영상/설명란에 "각색된 사연" 고지가 있는가?
- [ ] AI 생성 라벨이 켜져 있는가?

## 3. 저작권 / 음악

- **ACE Step v1.5 로 생성한 BGM**: MIT 라이선스 + **상업 이용 명시 허가** (HuggingFace 모델 카드 `ACE-Step/Ace-Step1.5` 기준 2026-04-23 확인). 학습 데이터도 라이선스/로열티프리/합성으로 공개.
- **Lyria 로 생성한 BGM (2026-04-22 이전 기록물)**: AI 생성이지만 상업적 이용 가능 (Google 의 Lyria 이용약관 기준 2026-04 시점 허용)
- **ElevenLabs TTS**: 유료 플랜에서 상업적 이용 가능. 무료 플랜은 YouTube/상업 용도 금지 — **유료 플랜 유지 필수**
- **실제 음악 인용 금지**: Spotify/Apple Music 등에서 다운로드한 음원을 배경으로 사용 금지 (Copyright Match 필연적)
- **효과음(SFX)**: Pixabay / Freesound CC0 만 사용. 출처 불분명한 SFX 금지

## 4. 플랫폼별 업로드 설정

### TikTok

| 항목 | 값 |
|---|---|
| 해상도 | 1080×1920 (9:16) |
| 프레임레이트 | 30fps |
| 길이 | 최대 10분 (우리 콘텐츠는 3분 이내) |
| 코덱 | H.264 + AAC |
| 워터마크 | 없음 (TikTok 이 자동 추가) |

### YouTube Shorts

| 항목 | 값 |
|---|---|
| 해상도 | 1080×1920 (9:16) |
| 길이 | **60초 이하** (60초 초과 시 Shorts 탭 제외 — 일반 영상으로 업로드됨) |
| 제목 해시태그 | `#shorts` 필수 |
| 설명 | AI 라벨 자동 삽입 + `#shorts` + 키워드 |

### Instagram Reels

| 항목 | 값 |
|---|---|
| 해상도 | 1080×1920 (9:16) |
| 길이 | 최대 90초 |
| 음악 라이선스 | 자체 생성 BGM 만 사용 (Instagram 음악 라이브러리는 비즈니스 계정 제한) |

### 우리 현재 콘텐츠

- 2:45 버전(175초) → **YouTube Shorts 규격 초과**. TikTok / 일반 YouTube 로만 업로드
- 60초 숏폼 버전 (추후 별도 제작) → 세 플랫폼 전부 가능

## 5. 채널 포지셔닝 (브랜드 일관성)

### 채널 한 줄 소개

"AI 가 각색한 사연 드라마. 실화 바탕, 각색 기반. 매일 한 편."

### 금기 사항

- ❌ "실화입니다" 주장 (각색임을 명시)
- ❌ 자살/자해/성폭력 자극적 묘사 (플랫폼 가이드라인 위반)
- ❌ 특정 성별/직업/지역 비하
- ❌ 미성년자 성적 묘사 (Imagen4 프롬프트에도 절대 금지)

### 권장 톤

- 담담한 내레이션 ("~했어요")
- 가해자·피해자 극단화 금지 (현실적 회색지대 유지)
- 해피엔딩 강요 금지 (현실 반영)

## 6. 위반 시 에스컬레이션

플랫폼 경고를 받았을 때:

1. **즉시 비공개 처리** (삭제 X — 기록 보존 목적)
2. `docs/FAILURE_CASES.md` 에 위반 사례 기록 (플랫폼 / 경고 내용 / 원인)
3. 파이프라인 변경 필요 여부 판단:
   - 프롬프트 때문이면 → `docs/PROMPTS.md` 수정
   - 각색 기준 때문이면 → 이 문서 §2 강화
4. 유사 영상 있으면 같은 기준으로 재검토
