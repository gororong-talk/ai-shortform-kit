# /produce-story-world — 인물-구동 롱폼 서사 자율 생성

단발 사연 각색(→ `/produce-sayeon`)과 별개 트랙. **인물을 깊게 박제 → 쇼러너가 무대에 올려 매 장면 인과-잠금하며 하나의 큰 이야기를 완성**하는 창작 파이프라인. 목표함수는 완주율(≤1:30 강점은 유지 못 하는 롱폼이므로 3부작으로 분할).

## 트리거
- 슬래시: `/produce-story-world [world_slug]`
- 자연어: "새 이야기 세계/드라마 만들어", "인물들 인격화해서 롱폼", "스토리 엔진 돌려"
- 전제: 이건 **감독(쇼러너)이 코어를 직접 잠그고** 나머지를 에이전트에 위임하는 반자율 작업. 완전 무인 아님.

## 아키텍처 (5유닛 — 상세 `story_engine/DESIGN.md`)
`(B)시더[사연씨앗] → (A)인물 바이블 → (D)쇼러너[아크·인과잠금] ⇄ (C)시뮬[장면] → (E)프로덕션 브리지`.
씨앗 = 실제 사연에서 인물 원형·극적 상황·말투 추출(우리 강점) + 창작 확장.

## Phase 0 — 세계관 코어 잠금 (감독 직접, 위임 금지)
`story_engine/<world_slug>/00_story_bible.md` 작성. 반드시 담을 것:
1. **시대적 배경**: 때·곳(가상 지명)·시대 공기·미술질감. 고증 앵커(제도·기술 연표)를 못박아 이후 위반을 기각 가능하게.
2. **무대 = 압력솥 공간**: 삶·죽음·돈·가족이 한 곳에서 교차하는 단일 무대(인물들이 자연히 엮이게). 공간 층위 = 계급.
3. **캐스트 로스터**: 5 코어 + 위성. **관계가 서로를 잠그도록**(A의 비밀을 B만 안다 식). 각 1줄 훅.
4. **발화점(개연적)**: 하나의 사건으로 전원을 점화. "누가 이렇게 만들었나"의 질문형.
5. **중심 극적 질문 + 톤**: "개연성 있는 막장"(막장강도↑ × 매 비트 인과잠금, 성인向·안전선 내).
6. **열린 흐름**: 기승전결 + 연재 훅(예측가능하되 열린 실 2~4개).
7. **잠금 규칙**: 인물 바이블 위반·시대 위반·별개정보(비인과) 비트는 기각.

## Phase 1 — 병렬 자율 인물생성 (에이전트 N개 = 코어 인원수)
코어 인물 1명당 general-purpose 에이전트 1개를 **한 블록에 병렬** 투입. 각 에이전트 프롬프트:
- 먼저 `00_story_bible.md`를 Read(카논, 모순 시 기각) 하게 할 것.
- 산출 2파일: `characters/<name>.md`(풀 바이블: 기본·성장환경·신체외형[레퍼런스잠금용 구체]·성격·**말투 대사샘플 6~8줄**[시뮬 연기용 핵심]·욕망/상처/비밀·관계역학·아크위치·열린실) + `jobs/<job>.md`(직업·시대 딥다이브, **필요시 WebSearch 고증**, 후대 기술 금지목록 명기).
- 비밀을 각자 개연적으로 설계하되 **충돌 가능성 있으면 "내 버전 명시, 감독이 조율"** 이라고 지시(Phase 2에서 조율).

## Phase 2 — 카논 조율 (감독 직접)
독립 생성이 만든 충돌·과잉을 `story_engine/<world_slug>/20_canon_lock.md`(SUPERSEDES)로 확정:
- **비밀 충돌**: 플롯-핵심(발화점과 인과로 묶이는) 버전을 척추로 채택, 나머지는 흡수/폐기.
- **상처 monoculture 방지**(★함정1): 여러 에이전트가 같은 상처를 독립 설계함 → 장소·결과·메커니즘을 **분화**(공명은 살리되 우연 제거).
- 물증·타임라인·나이 **통일**.
- 그리고 `10_arc.md`(기승전결 비트시트) 작성/갱신.

## Phase 3 — 완결본 집필 (감독 직접)
`story_engine/<world_slug>/COMPLETE_STORY.md`. 원칙:
- **★기본은 선형(시간순)·단일 POV·쉬운 흐름**(함정8). 초5도 따라올 수준. 짧은 콜드오픈(~15초) 훅만 예외, 그 뒤론 안 튄다. 과거 회상은 클라이맥스에서 **딱 한 번** 명확히.
- **씨앗은 앞에 심고 뒤에 회수**(정서 정점의 사실은 관객이 이미 쥐고 있어야 터진다).
- **POV 앵커 1명**(전편 관통). 비선형/라쇼몽/다중시점은 **금지 기본**(작품성 욕심 주의 — 텍스트·완주율 둘 다 무너뜨림).
- **클라이맥스 = 공동목격**(한 명이 독점하면 나머지 arc가 화면에서 안 닫힘).
- 매 비트 인과잠금(그래서→그랬더니). 미워할 얼굴을 초반에 세운다.
- 전문용어(제도·금융)는 **초등학생 말**로 푼다(예: "미수금"→"못 낸 치료비", "이중장부"→"몰래 쓴 가짜 장부").

## Phase 4 — 3렌즈 적대검증 (에이전트 3개 병렬)
각 general-purpose 에이전트에 전체 파일(00·10·20·COMPLETE_STORY·characters·jobs) 정독 + **적대적으로 허점 찾고 구체 수정안** 지시:
1. **개연성**: 인과잠금·플롯홀·시대고증·인물정합·타임라인·법의학/직업 단서 자기모순.
2. **서사구조**: 기승전결 균형·복선 회수·정서정점 페이오프·시점배분·결말 획득감.
3. **흡입력(완주율)**: 첫3초훅·이탈위험 지도·막장강도·감정이입·롱폼 vs 중폼·클릭카피.

## Phase 5 — 갭 통합 + 정합 패스 (감독 + 에이전트 1)
- 세 보고의 급소를 통합해 COMPLETE_STORY·20_canon_lock 갱신. 구(舊)본은 `[SUPERSEDED]` 표기.
- **정합 패스**(★함정3): stale 인물파일이 폐기설정을 잠근 채 남으면 콘티/나레이션 자동생성 시 오염 재유입 → 에이전트 1개로 인물파일을 canon_lock에 맞춰 SUPERSEDED 정합.
- 완료 후 `python scripts/validate_skills.py`는 스킬 검증용(이야기 검증 아님).

## ★ 재발방지 함정 (World01 파일럿 실측 — 반드시 점검)
1. **상처 monoculture**: 병렬 인물생성은 같은 원상처(예: "가족이 병원 문턱에서 돈 때문에 죽음")를 독립 남발한다 → Phase 2에서 메커니즘 분화.
2. **괄호 지문 = 관객 미수신**: 정서 정점의 씨앗을 `(그는 몰랐다…)` 같은 연출메모에만 두면 관객이 못 받아 정점이 뭉개진다 → 화면·대사·나레이션으로 승격.
3. **stale 인물파일 오염**: 폐기된 초안 설정이 파일에 남음 → 콘티 생성 전 "인물파일 vs 20_canon_lock diff" 게이트(정합 에이전트).
4. **무검증 롱폼 리스크**: 12~15분 단일편 완주율 데이터 사실상 없음 → **3부작 4~6분 default**(전환장치 A/B[회차·다음편떡밥]와도 정합). 단일 롱폼은 6~8분 먼저 실측 후 확장.
5. **발화 사건 단일 확정**: 죽음/사건의 위치·시점이 상위 두 카논에서 갈리면 훅·단서·인과가 도미노로 붕괴 → 한 곳으로 잠금.
6. **직업/법의학 단서 교차검증**: 단서(무처치흔 등)가 다른 씬(수액 처치)과 모순되지 않는지 자기 직업파일과 대조.
7. **시대고증 금지목록**: 각 jobs/ 파일에 후대 기술·제도(EMR·전산경고·상조 등) 금지목록을 명기해 자동생성 위반 차단.
8. **★비선형·다중시점 = 혼란**(World01 v2 실측): 훅→되감기→현재→과거 식 시간층 3개 + 라쇼몽(같은 장면 다시점 반복)을 남겼더니 사용자가 "앞뒤 혼재로 헷갈린다"고 정정. 텍스트로도, 완주율로도 무너진다. → **기본 = 선형·단일 POV·초5 수준 쉬운 흐름**. 과거는 클라이맥스 회상 1회만. "작품성" 욕심에 시간점프 넣지 말 것(감독이 v2에서 저지른 실수).
9. **★이미지 제작(fal.ai) 2대 함정**(World01 1부 실측):
   (a) **캐릭터 일관성 = 텍스트만으론 실패**. 텍스트→이미지(schnell)는 인물이 컷마다 다르고 2인 장면에서 한 명이 누락됨. → **인물 앵커 7종 먼저 생성(`--prompt/--out _ref_<role>.png`) → `--production --flux2 --ref <role>=path`로 비트 재생성**. 다인물 컷은 `--flux2`(FLUX.2 edit) 필수(kontext 4인 병합 회피). 검증됨: 앵커 잠금 후 도현·순덕·오만복 매 컷 동일.
   (b) **FLUX.2 edit 콘텐츠체커가 죽음·피·시신·폭력·위협뿐 아니라 예측 못 한 단어에도 걸림**(World01 1~3부+사연 2건, 총 28건 실측). 막장·갈등 드라마는 필연적으로 걸린다. 체커는 **비결정적**(같은 프롬프트가 재시도에서 통과하기도 함) → 대응 순서: **①그대로 1~2회 재시도(flaky면 통과) → ②트리거 의심 단어 순화 후 재시도 → ③그래도 막히면 `--style webtoon`(schnell text→image)로 폴백**(인물 일관성은 약간 희생하나 CTA·단독 클로즈업 등 비중요 컷엔 허용).
      **확인된 트리거 단어/구문**(발견 즉시 이 목록에 추가): `blood/corpse/mortuary/dead/deceased/departed/frozen(죽음 의미)/battlefield/cruel/collapse·collapsing(쓰러짐)/threatening/threat/disembodied hands(신체 없이 손만 묘사)/ghostly/haunted/scratch(상처)/testify` + **여성 인물 단독 정면 클로즈업+"looking directly at the viewer"류 직시 구도**(원인 불명, 재현됨 — 순화보다 구도 자체를 살짝 틀거나 ③폴백이 빠름) + **여성 인물 단독 + 저녁/밤 시간대 + 램프·조명(lamp-lit) 구도**(reflexive_denial 사연 B06/B08 실측, 원인 불명 — 낮 시간대 배경으로 바꾸면 대부분 통과).
      **순화 패턴**: 피토→"기침하며 무릎 꿇음" / 시신·영안실→"흰 천으로 덮인 조용한 안치 준비실" / frozen dead→"hunched still" / collapse→"sinks down to sit"(주저앉음으로) / "a pair of hands"→인물 이름 주어로 재기술 / "threatening message"→"an incoming message"(threatening만 제거) / 직시 클로즈업→"gaze slightly off to the side"로 시선 비틀기 / 여성 단독+저녁/램프 조명 구도→낮 시간대·자연광으로 변경.
   (c) 부수: FLUX는 negative 무시 → 가짜 코너 서명·1997 시대위반(LCD 모니터)이 일부 컷에 샘. 크롭/노멀라이즈 또는 재생성으로 개별 처리.

## 다음 (제작 브리지 = E 유닛, World01 3부작 실측 절차)
COMPLETE_STORY 1부부터 기존 파이프라인으로 렌더. `story_engine/<world>/production/part<N>/`는 **비표준 경로**라 기존 스크립트(`productions/<slug>/` 가정)와 연결하려면 아래 순서를 그대로 따른다:

1. **나레이션**: `.claude/skills/draft-narration/SKILL.md` 원칙(콜드오픈·인과잠금·다음편떡밥)을 3인칭 롱폼용으로 적응. 이 편의 cliffhanger를 다음편 떡밥으로 쓰는 건 **연재물이라 정당한 예외**(사연 트랙의 "미완결 cliffhanger 금지" 원칙 비적용).
2. **08 시트**: `.claude/skills/generate-hybrid-sheet/SKILL.md` 스타일·no-text 규칙 채택하되 헤더는 **반드시 `## B##`**(fal 파서 계약 — `###`나 다른 포맷 쓰면 0비트 파싱, 1부에서 실제로 겪음). `_beat_map.json` 값은 **항상 리스트** `{"1":[1],...}`(정수 아님 — `generate_narration_fish.py`가 `len()` 호출해 크래시).
3. **심볼릭 링크**(기존 스크립트가 `productions/<slug>/`를 하드코딩): `ln -sfn "$PWD/story_engine/<world>/production/part<N>" "$PWD/productions/<world>_p<N>"`
4. **캐릭터 앵커**: 1부에서 `--prompt/--out _ref_<role>.png`로 역할별 1장씩 생성 후 **전편 재사용**(2·3부는 재생성 안 함, 동일 인물 일관성+비용절감).
5. **이미지**: `generate_images_fal.py --production <world>_p<N> --flux2 --ref <role>=<path> ...` 반복. **콘텐츠필터 대응**(함정9 참조) — 실패 프롬프트를 읽고 순화, 최대 2회 재시도(체커 비결정성), 그래도 막히면 `--style webtoon`(text→image) 폴백.
6. **TTS+합성**: `generate_narration_fish.py <world>_p<N> --voice m_doctor_calm`(드라마 톤) → `compose_narration.py <world>_p<N> --kenburns`.
7. **전달 압축 = 반드시 `scripts/compress_for_delivery.py`**(★재발방지, 아래 참조). Raw ffmpeg 명령을 손으로 다시 짜지 말 것.
8. **IG 분할**(3분 초과 시, IG 탐색추천 3분 상한): `04_timing.json`의 `subtitles[].start`에서 절반 지점과 가장 가까운 **장면 경계**(내용상 자연스러운 컷) 라인을 골라 `ffmpeg -t <T>`/`ffmpeg -ss <T>`로 2분할 후 각각 `compress_for_delivery.py --file`.
9. **게시 메타**: `_pubmeta.json` 수작성(사연과 달리 회차번호 대신 `EP.N`, "각색 사연" 대신 "창작 드라마" 고지, AI라벨 ON) → `prep_upload.py <world>_p<N> --no-open`로 `.command` 4종 드롭. IG 분할 시 통짜 `.command` 대신 `인스타_a/b_복사.command` 각각 생성.
- 롱폼 ≥10분 = YouTube 일반영상(Shorts 아님). 3부작(4~6분씩)은 Shorts/일반 자동판정(≤3분=Shorts 가능성, 우리는 일반영상 통일 권장).

### ★재발방지 — 기존 스크립트 우선 검색 (World01 3부작 실측, 함정10)
이번 3부작 제작 중 **`ffmpeg -crf 26~28`로 30MB 이하 압축을 raw 명령으로 10회 재발명**했다. 그런데 `scripts/compress_for_delivery.py`가 **이미 존재**했다(stale-render 가드+적응형 ceiling 24MB+crf30, [[stale-render-and-foreground-text-qc]] 학습을 반영한 정식 도구). `--file <임의경로>` 옵션이 있어 `story_engine/` 비표준 경로에도 그대로 쓸 수 있다(검증됨). → **새 작업(특히 "전달/압축/변환"류) 전에 먼저 `ls scripts/ | grep -i <키워드>`로 기존 도구 유무를 확인**. 사연 파이프라인에 있는 기능(압축·타임라인 파싱 등)은 드라마 트랙에도 대개 재사용 가능하다.
